Thrust Model

The main propulsion system in Moonlander is modeled as a first-order dynamic system. The actual thrust force approaches the commanded thrust force exponentially, with a time constant representing the engine response delay.

Assumptions:

The engine cannot change its thrust force instantaneously. Instead, it behaves like a first-order system (PT1 / first-order lag) with time constant τ\tauτ.

This model class is mathematically equivalent to:
- RC circuits
- Thermal inertia
- Motor spin-up dynamics
- Low-pass filters

Physical / System Formulation:

The rate of change of thrust force is proportional to the difference between commanded and actual thrust force:

F˙T∝(FT,cmd−FT) \dot{F}_T \propto (F_{T,cmd}-F_T) F˙T​∝(FT,cmd​−FT​)

Introducing the proportionality constant1τ\frac{1}{\tau}τ1​:

F˙T=1τ(FT,cmd−FT) \dot{F}_T = \frac{1}{\tau} (F_{T,cmd}-F_T) F˙T​=τ1​(FT,cmd​−FT​)

Interpretation:

- FT,cmdF_{T,cmd}FT,cmd​: commanded thrust force [N]
- FTF_TFT​: actual thrust force [N]
- τ\tauτ: engine response time / inertia [s]

Limiting cases:
- τ→0\tau \rightarrow 0τ→0 → instantaneous response
- Large τ\tauτ → slow engine response

Discrete Form (from ODE)

Starting from:

F˙T=FT,cmd−FTτ \dot{F}_T = \frac{F_{T,cmd}-F_T}{\tau} F˙T​=τFT,cmd​−FT​​

Assuming FT,cmdF_{T,cmd}FT,cmd​ is constant over a timestepΔt\Delta tΔt, the analytical solution becomes:

FT(t+Δt)=FT(t)e−Δt/τ+FT,cmd(1−e−Δt/τ) F_T(t+\Delta t) = F_T(t)e^{-\Delta t/\tau} + F_{T,cmd} (1-e^{-\Delta t/\tau}) FT​(t+Δt)=FT​(t)e−Δt/τ+FT,cmd​(1−e−Δt/τ)

Rearranged:

FT,k+1=FT,k+(1−e−Δt/τ)(FT,cmd,k−FT,k) F_{T,k+1} = F_{T,k} + (1-e^{-\Delta t/\tau}) (F_{T,cmd,k}-F_{T,k}) FT,k+1​=FT,k​+(1−e−Δt/τ)(FT,cmd,k​−FT,k​)

Step-by-Step Solution of the Differential Equation

We solve the first-order ODE:

F˙T=FT,cmd−FTτ \dot{F}_T = \frac{F_{T,cmd}-F_T}{\tau} F˙T​=τFT,cmd​−FT​​

Step 1: Rearrange

Bring the equation into standard linear form:

F˙T+1τFT=FT,cmdτ \dot{F}_T + \frac{1}{\tau}F_T = \frac{F_{T,cmd}}{\tau} F˙T​+τ1​FT​=τFT,cmd​​

Denote:

a=1τ,b=FT,cmdτ a=\frac{1}{\tau}, \quad b=\frac{F_{T,cmd}}{\tau} a=τ1​,b=τFT,cmd​​

Step 2: Homogeneous Solution

Solve:

F˙T,h+aFT,h=0 \dot{F}_{T,h} + aF_{T,h} = 0 F˙T,h​+aFT,h​=0

Using exponential ansatz:

FT,h(t)=Ce−at=Ce−t/τ F_{T,h}(t) = Ce^{-at} = Ce^{-t/\tau} FT,h​(t)=Ce−at=Ce−t/τ

Step 3: Particular Solution

Since the forcing term is constant, use:FT,p=kF_{T,p}=kFT,p​=k.

Substituting into the ODE:

0+ak=b  ⟹  k=FT,cmd 0+ak=b \implies k=F_{T,cmd} 0+ak=b⟹k=FT,cmd​

Step 4: General Solution

FT(t)=FT,h(t)+FT,p=Ce−t/τ+FT,cmd F_T(t) = F_{T,h}(t) + F_{T,p} = Ce^{-t/\tau} + F_{T,cmd} FT​(t)=FT,h​(t)+FT,p​=Ce−t/τ+FT,cmd​

Step 5: Apply Initial Condition

At t=0t=0t=0,FT(0)=FT,0F_T(0)=F_{T,0}FT​(0)=FT,0​:

FT,0=C+FT,cmd  ⟹  C=FT,0−FT,cmd F_{T,0} = C+F_{T,cmd} \implies C = F_{T,0}-F_{T,cmd} FT,0​=C+FT,cmd​⟹C=FT,0​−FT,cmd​

Step 6: Evaluate at t + Δt

FT(t+Δt)=(FT,0−FT,cmd)e−Δt/τ+FT,cmd F_T(t+\Delta t) = (F_{T,0}-F_{T,cmd}) e^{-\Delta t/\tau} + F_{T,cmd} FT​(t+Δt)=(FT,0​−FT,cmd​)e−Δt/τ+FT,cmd​

Expanding usingFT,0=FT(t)F_{T,0}=F_T(t)FT,0​=FT​(t):

FT(t+Δt)=FT(t)e−Δt/τ+FT,cmd(1−e−Δt/τ) F_T(t+\Delta t) = F_T(t)e^{-\Delta t/\tau} + F_{T,cmd} (1-e^{-\Delta t/\tau}) FT​(t+Δt)=FT​(t)e−Δt/τ+FT,cmd​(1−e−Δt/τ)

Step 7: Intuition

- The system always converges towardFT,cmdF_{T,cmd}FT,cmd​.
- The convergence speed is governed byτ\tauτ.
- Smaller τ\tauτ → faster response.
- Larger τ\tauτ → slower response.

Fuel Consumption

The specific impulse is defined as:

Isp=FTm˙g0 I_{sp} = \frac{F_T}{\dot{m}g_0} Isp​=m˙g0​FT​​

Where:
- IspI_{sp}Isp​: specific impulse [s]
- FTF_TFT​: thrust force [N]
- g0≈9.81g_0 \approx 9.81g0​≈9.81: standard gravity [m/s²]

Solving for mass flow rate:

m˙=FTIspg0 \dot{m} = \frac{F_T}{I_{sp}g_0} m˙=Isp​g0​FT​​

Fuel mass decreases according to:

m˙f=−FTIspg0 \dot{m}_f = - \frac{F_T}{I_{sp}g_0} m˙f​=−Isp​g0​FT​​

Key Characteristics

  • First-order exponential response to commanded thrust force
  • Stable analytical discrete-time formulation
  • Real-time capable low-order propulsion model
  • Physically coupled fuel consumption
  • Suitable for guidance and control simulation
  • Numerically stable for variable simulation timesteps
