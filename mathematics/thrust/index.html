Thrust Model

The thrust system in Moonlander is modeled as a first-order dynamic system. The actual thrust approaches the target thrust exponentially, with a time constant representing the engine's response delay.

Assumptions:

The engine cannot change its thrust instantaneously. Instead, it behaves like a first-order system (PT1 / first-order lag) with time constant τ\tauτ.

This model class is the same as:
- RC circuits
- Thermal inertia
- Motor spin-up dynamics
- Low-pass filters

Physical / System Formulation:

The rate of change of thrust is proportional to the difference between commanded and actual thrust:

F˙∝(Fcmd−F)\dot{F} \propto (F_{cmd} - F)F˙∝(Fcmd​−F)
Introducing the proportionality constant 1τ\frac{1}{\tau}τ1​:
F˙=1τ(Fcmd−F)\dot{F} = \frac{1}{\tau} (F_{cmd} - F)F˙=τ1​(Fcmd​−F)

Interpretation:
- FcmdF_{cmd}Fcmd​: commanded thrust [N]
- FFF: actual thrust [N]
- τ\tauτ: engine response time / inertia [s]
Limited cases:
- τ→0\tau \rightarrow 0τ→0: instantaneous response
- Large τ\tauτ: slow engine response

Discrete Form (from ODE)
Start from:

F˙=(Fcmd−F)τ\dot{F} = \frac{(F_{cmd} - F)}{\tau}F˙=τ(Fcmd​−F)​
Assuming FcmdF_{cmd}Fcmd​ is constant over a timestep Δt\Delta tΔt, the solution is:
F(t+Δt)=F(t)e−Δt/τ+Fcmd(1−e−Δt/τ)F(t + \Delta t) = F(t) e^{-\Delta t / \tau} + F_{cmd} (1 - e^{-\Delta t / \tau})F(t+Δt)=F(t)e−Δt/τ+Fcmd​(1−e−Δt/τ)
Rearranged:
Fk+1=Fk+(1−e−Δt/τ)(Fcmd,k−Fk)F_{k + 1} = F_k + (1 - e^{-\Delta t / \tau})(F_{cmd, k} - F_k)Fk+1​=Fk​+(1−e−Δt/τ)(Fcmd,k​−Fk​)

Step-by-Step Solution of the Differential Equation

We solve the first-order ODE:

F˙=Fcmd−Fτ\dot{F} = \frac{F_{cmd} - F}{\tau}F˙=τFcmd​−F​

Step 1: Rearrange
Bring into standard linear form:

F˙+1τF=Fcmdτ\dot{F} + \frac{1}{\tau} F = \frac{F_{cmd}}{\tau}F˙+τ1​F=τFcmd​​
Denote:
a=1τ,b=Fcmdτa = \frac{1}{\tau}, \quad b = \frac{F_{cmd}}{\tau}a=τ1​,b=τFcmd​​

Step 2: Homogeneous Solution
Solve

F˙h+aFh=0\dot{F}_h + a F_h = 0F˙h​+aFh​=0
Using exponential ansatz:
Fh(t)=Ce−at=Ce−t/τF_h(t) = C e^{-a t} = C e^{-t/\tau}Fh​(t)=Ce−at=Ce−t/τ

Step 3: Particular Solution
Since the forcing term is constant, try Fp=kF_p = kFp​=k.
Substitute into ODE:

0+ak=b  ⟹  k=Fcmd0 + a k = b \implies k = F_{cmd}0+ak=b⟹k=Fcmd​

Step 4: General Solution

F(t)=Fh(t)+Fp=Ce−t/τ+FcmdF(t) = F_h(t) + F_p = C e^{-t/\tau} + F_{cmd}F(t)=Fh​(t)+Fp​=Ce−t/τ+Fcmd​

Step 5: Apply Initial Condition
At t=0t = 0t=0, F(0)=F0F(0) = F_0F(0)=F0​:

F0=C+Fcmd  ⟹  C=F0−FcmdF_0 = C + F_{cmd} \implies C = F_0 - F_{cmd}F0​=C+Fcmd​⟹C=F0​−Fcmd​

Step 6: Evaluate at t + Δt

F(t+Δt)=(F0−Fcmd)e−Δt/τ+FcmdF(t + \Delta t) = (F_0 - F_{cmd}) e^{-\Delta t/\tau} + F_{cmd}F(t+Δt)=(F0​−Fcmd​)e−Δt/τ+Fcmd​
Expanding using F0=F(t)F_0 = F(t)F0​=F(t):
F(t+Δt)=F(t)e−Δt/τ+Fcmd(1−e−Δt/τ)F(t + \Delta t) = F(t) e^{-\Delta t / \tau} + F_{cmd} (1 - e^{-\Delta t / \tau})F(t+Δt)=F(t)e−Δt/τ+Fcmd​(1−e−Δt/τ)

Step 7: Intuition
- The system always moves toward FcmdF_{cmd}Fcmd​.
- The speed of convergence is governed by τ\tauτ.
- Smaller τ\tauτ → faster response.
- Larger τ\tauτ → slower response.

Fuel Consumption

Specific impulse is defined as:

Isp=Fm˙g0I_{sp} = \frac{F}{\dot{m} g_0}Isp​=m˙g0​F​
Where:
- IspI_{sp}Isp​ : specific impulse [s]
- FFF : thrust [N]
- g0≈9.81g_0 \approx 9.81g0​≈9.81 : standard gravity [m/s²]

Solving for mass flow rate:

m˙=FIspg0\dot{m} = \frac{F}{I_{sp} g_0}m˙=Isp​g0​F​
Fuel mass decreases:
m˙f=−FIspg0\dot{m}_f = -\frac{F}{I_{sp} g_0}m˙f​=−Isp​g0​F​
