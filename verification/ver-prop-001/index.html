VER-PROP-001 · PASS

Propulsion Force and Torque Generation

This verification package demonstrates that the SDF propulsion subsystem produces the expected main-engine and RCS thrust vectors, force aggregation, torque generation, and body-axis sign conventions.

Verification Objective

VER-PROP-001 verifies the production propulsion path from commanded engine state to resulting spacecraft-body-fixed force and torque. The cases isolate propulsion behavior from downstream frame transformation and translational state propagation, so force and torque generation can be assessed independently.

Scope of Evidence

Passing VER-PROP-001 demonstrates that propulsion force and torque generation is internally consistent in SBF for the bounded reference cases above. It does not verify downstream SBF-to-MCI transformation, acceleration calculation, state propagation, or complete spacecraft response.
